Semua yang dibutuhkan aplikasi desktop

NXC menyediakan mekanismenya; Anda menentukan isi aplikasinya.

window

Window Fluent

Frameless ala Windows 11: title bar kustom, resize dari tepi, sudut membulat, dan Mica — tanpa garis tepi.

keyboard

Keyboard & Shortcut

Shortcut terpusat dengan scope Application/Window/Context, chord (Ctrl+K, Ctrl+S), deteksi konflik, dan enable/disable.

terminal

Terminal sungguhan

PTY + emulator VT: ketik langsung, warna, Tab-completion, saran PowerShell 7, dan vim — seperti terminal asli.

palette

Tema & preferensi

Tema gelap/terang hot-swap, preferensi tersimpan otomatis, dan tray icon dengan menu standar.

route

Routing halaman

Router bergaya web — rute /produk/:id, query, back/forward — plus sidebar navigasi Fluent.

hub

Runtime bridge

Panggil JavaScript in-process, Node.js, atau Python lewat satu protokol pesan JSON yang sama.

Runtime opsional, sesuai kebutuhan

Mulai murni C++/Qt, lalu tambahkan JavaScript, Node.js, atau Python hanya bila aplikasi Anda memerlukannya.

C++ / Qt

Core native — wajib ada di setiap aplikasi NXC.

+ JavaScript

In-process (QJSEngine) untuk scripting ringan, plugin, dan automation.

+ Node.js

Out-of-process untuk ekosistem npm, tooling, dan layanan.

+ Python

Untuk AI, machine learning, data, dan komputasi ilmiah.

Bisa juga dipakai semuanya sekaligus — satu protokol pesan JSON yang sama.

Sedikit kode, aplikasi jadi

Turunkan nxc::Window, serahkan pabriknya ke nxc::Application. 

#include <nxc/Application.h>
#include <nxc/Window.h>

int main(int argc, char* argv[]) {
    nxc::Application app(argc, argv);
    app.setApplicationName("Aplikasi Saya");
    app.setWindowFactory([] { return new MyWindow; });
    return app.exec();
}
#include <nxc/Window.h>

class MyWindow : public nxc::Window {
public:
    MyWindow() {
        setTitle("Aplikasi Saya");
        setContent(new MyContentWidget(this));

        auto* file = menuBar()->addMenu("File");
        file->addAction("Keluar", this, &QWidget::close);
    }
};
find_package(nxc CONFIG REQUIRED)
target_link_libraries(myapp PRIVATE nxc::nxc Qt6::Widgets)
nxc_deploy(myapp)   # salin nxc.dll + DLL Qt setelah build

  • Satu binary ringan

    Jauh lebih kecil dari Electron — tanpa Chromium, tanpa Node di dalam paket.

  • API publik yang stabil

    22 header di namespace nxc, kompatibilitas SameMajorVersion.

  • Deploy otomatis

    nxc_deploy() menyalin DLL yang dibutuhkan — exe langsung jalan.

Mulai cepat

Satu perintah membuat project siap build.

Terminal
$ npm create nxc-app@latest MyApp
$ cd MyApp
$ npm run dev # build Debug + jalankan
$ npm run dist # installer / paket siap bagi

  1. Prasyarat

    Qt 6.8 (kit MSVC 2022 64-bit), Visual Studio 2022 Build Tools, CMake ≥ 3.21, Node.js ≥ 18.

  2. Scaffold

    Perintah membuat CMakeLists, preset, dan struktur src/, lalu mengunduh SDK dari Releases.

  3. Build & jalankan

    npm run dev build Debug dan langsung menjalankan aplikasi.

Modul opsional

Library terpisah — hanya ikut dibawa kalau aplikasi Anda memakainya.

nxc_database.dll

Database

SQLite (atau driver lain), koneksi per thread, query async, transaksi, dan migrasi NNN_nama.sql.

<nxc/Database.h>
nxc_websocket.dll

WebSocket

Client dengan reconnect + backoff eksponensial, antrean pesan saat offline, ping keepalive, dan helper JSON.

<nxc/WebSocket.h>
find_package(nxc CONFIG REQUIRED COMPONENTS Database WebSocket)
